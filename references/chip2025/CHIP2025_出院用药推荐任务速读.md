# CHIP 2025 评测二｜出院用药推荐任务速读

**给模型一次住院的脱敏中文电子病历，让它从 651 种候选药物中选出这次出院带药的名称集合。** 这是一个固定候选集的多标签预测任务。评测以医生实际开具的出院带药为参考，只比较药名集合，药名顺序、剂量、频次和疗程均不计分。 [官方赛题](http://www.cips-chip.org.cn/2025/eval2)

## 输入、标签和提交

| 内容 | 关键点 |
| --- | --- |
| 预测单位 | 一条记录对应一次住院就诊。一个患者可以有多次就诊，提交用**就诊标识**。 |
| 模型输入 | 主诉、现病史、既往史、入院情况、诊疗过程（含检验检查）和出院诊断。另有人口学信息、BMI 和时间字段。 |
| 训练标签 | `出院带药列表`。训练集提供标签，A 榜和 B 榜隐藏标签，由平台评分。 |
| 提交文件 | UTF-8 编码的 JSON 数组，覆盖对应测试集的每条就诊。`ID` 填就诊标识，`prediction` 填候选表中的标准药名数组。 |

下面用占位药名演示文件结构。 [官方赛题与提交说明](http://www.cips-chip.org.cn/2025/eval2)

```json
[{"ID": "1-1", "prediction": ["药物A", "药物B"]}]
```

## 数据与划分

**CDrugRed** 来自大连医科大学附属第二医院，涵盖 2013–2023 年的 5,894 条脱敏住院记录，涉及 3,190 名患者。 [数据集论文 v1](https://arxiv.org/pdf/2510.21084v1)

| 划分 | 患者数 | 就诊数 | 用途 |
| --- | ---: | ---: | --- |
| 训练集 | 1,910 | 3,602 | 有标签，训练和内部验证 |
| 开发集（A 榜） | 320 | 570 | 线上调试 |
| 测试集（B 榜） | 960 | 1,722 | 最终排名 |

官方按患者划分，同一人的多次就诊归入同一子集。自己从训练集切验证集时，也应按`患者序号`分组，避免同一人的相似病历出现在两边。 [组织方总结 §3.2](https://arxiv.org/pdf/2511.06230#page=5)

## 怎么评分

每次就诊先单独算 Jaccard 和 F1，再分别对所有就诊取平均。**总分 =（平均 Jaccard + 平均 F1）÷ 2**。 [官方评价指标](http://www.cips-chip.org.cn/2025/eval2)

| 单条就诊指标 | 计算方式 |
| --- | --- |
| Jaccard | 命中药数 ÷ 真实与预测药物的并集大小 |
| F1 | 2 × 命中药数 ÷（真实药数 + 预测药数） |

例如，真实为 `{A, B, C}`，预测为 `{A, B, D}`，有 2 个命中、1 个漏报、1 个多报。Jaccard 为 `2/4 = 0.50`，F1 为 `4/6 ≈ 0.67`。输出多少种药和选哪些药都影响分数。这个分数衡量对历史处方的复现程度，临床安全性和跨医院泛化需单独验证。 [组织方总结 §3.4、§5](https://arxiv.org/pdf/2511.06230)

## 建模时最值得关注的三件事

1. **先量化病历各字段的价值。** 可以用“训练集高频药”作简单基线，再用中文字符 n-gram TF-IDF 加多标签逻辑回归，比较仅用出院诊断和加入诊疗过程的分数。病历中曾使用、临时使用或已停用的药，需要结合上下文区分。
2. **观察药物长尾，并用验证集确定预测数量。** 数据集平均每次就诊约 6.1 种带药，651 种候选药中仅 586 种在训练标签里出现。用内部验证集按总分选输出阈值，额外观察低频药的召回。 [数据集论文表 2](https://arxiv.org/pdf/2510.21084v1#page=9)
3. **用候选词表约束输出，再比较复杂模型。** 分类器可直接输出候选表标签。生成式模型则应做药名归一和去重。官方基线是 GLM4-9B-Chat + LoRA，在 B 榜总分为 **0.5062**。第一名用特征增强和模型融合达到 **0.5685**。 [组织方总结 §4](https://arxiv.org/pdf/2511.06230#page=8)
